# Calculator
[![CI](https://github.com/sajidkamaljoy/Calculator/actions/workflows/ci.yml/badge.svg)](https://github.com/sajidkamaljoy/Calculator/actions/workflows/ci.yml)

A Windows Forms (.NET Framework 4.7.2) project created as a starting point for a desktop calculator.

## Current state

This is only the project scaffold. It contains an empty `Form1` with no buttons, display or calculation logic yet.

## Run it

1. Open `Calculator.sln` in Visual Studio.
2. Press F5. A blank window opens.

## Ideas for next steps

- Add digit and operator buttons and a display box to `Form1`.
- Handle `+ - × ÷`, clear and decimal input in `Form1.cs`.
- Guard against divide-by-zero.
